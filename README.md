# Оракул школы (Edu_Bot)

Бот школьного расписания для VK и MAX. Работает одновременно в обоих
мессенджерах с общим кэшем расписания, меню и замен.

- **MAX:** https://max.ru/ideya_fiks_7_bot
- **VK:** https://vk.ru/club242725074

## Что умеет

| Команда | Результат |
|---|---|
| `9А понедельник` | расписание класса на день |
| `Иванов вторник` | расписание учителя (по фамилии, с опечатками) |
| `меню` / `меню среда` | меню питания |
| `изменения пятница` | замены на день |
| `замены` | пошаговый подбор замены (для завучей) |
| `учителя` | список всех учителей |
| `начало` / `помощь` | справка |

Замены также можно загрузить файлом — xlsx («Замены…») или docx
(«Изменения в расписании на…»). Кэш общий: файл, присланный в одном
мессенджере, сразу виден в другом.

## Приватность

Бот не собирает и не хранит личные данные пользователей. На диск пишутся
только два лога: `log_statistic.txt` — обезличенные счётчики запросов по
классам/учителям, `log_error.txt` — только нераспознанные запросы, без
привязки к отправителю.

## Запуск

```bash
pip install -r requirements.txt
python3 school_bot.py
```

Токены — в `.env` рядом со скриптом:
```
VK_TOKEN=...
MAX_TOKEN=...
```

Или в Docker:
```bash
docker compose up -d --build
```

Повторный запуск второго экземпляра бот блокирует сам (`school_bot.lock`) —
защита от задвоенных ответов в VK.

## Обновление данных

Замените `schedule.xlsx` / `меню 1-4.xlsx` / `меню 5-11.xlsx` и
перезапустите бота — кэш пересоберётся автоматически, если файл новее.
